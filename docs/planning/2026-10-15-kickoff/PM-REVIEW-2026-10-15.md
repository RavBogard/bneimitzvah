## Findings and implementation direction

1. **The mission is coherent; the delivery order delays learning.** The study page and tutor recordings can support an early supervised usability pilot. Recommend adding that pilot after Phase 4, before MCP and generated chant; retain the full 1.0 gate. This is a proposal, not an approved removal of scope or release gate.
2. **Child access needs an explicit identity model.** Parent email alone cannot identify a child, especially with siblings. The auth spec must cover guardian identity, authorized child selection, clear mode switching, invitation replay, revoked relationships, and account linking. Roles may overlap (a tutor may also be a parent); avoid a schema that silently grants union permissions in every context.
3. **Private recordings require actual private delivery.** Do not implement the plan's public-Blob/random-key fallback. Use private storage with authorization for delivery and uploads, tenant/student relationships, size/type/duration checks, and revocation behavior. Confirm provider capability before provisioning. Retention and deletion policy remain decisions needed before real recordings ship.
4. **The public-repository guard is necessary but incomplete.** Inspect indexed and candidate files so the first untracked scaffold cannot pass an empty scan. Test the guard against representative violations. Marker scans do not establish license compliance or detect all personal data. Before publishing extracted history, audit every retained historical blob and metadata for prohibited material. Do not infer publication rights from existing public availability.
5. **Chant approval must bind to immutable content.** Before Phase 6, specify release identity including reviewed render hashes, melody-table version, voice, renderer version, and relevant flags. Public delivery must contain only approved output; a gated UI cannot protect an already-public unapproved audio URL.
6. **Tenancy needs enforceable relationships.** Tenant columns and query conventions are a starting point. The auth/data spec must define composite relationship constraints, authorization at each action, host allowlisting, preview configuration, and tests that deny guessed cross-tenant identifiers. Defaulting an unknown host to CRC is unacceptable.
7. **The learning experience needs a clear entry point.** Keep the assigned passage and a clear practice action primary. Treat word tools and commentary as contextual depth. Stable verse references matter for Zoom teaching; synchronized lessons/video features are not implied scope.
