# STEP source delivery checkpoint

Implemented a server-only source factory with no constructor I/O, caller configuration, environment credentials, runtime wiring, routes or public source payloads. `createStepSource()` exposes `book(code, signal?)` and `lexicon(signal?)`. Production URLs, source commit, expected lengths/digests and supported book mapping are fixed in `source-manifest.ts`. Even the separate trusted synthetic fixture constructor confines URL/pin/source/book identities to that manifest; only transport, tiny fixture integrity metadata, synchronous parsers and test clock/deadline are injectable there. The accepted pure STEP/morphology adapters are unchanged.

One producer slot for books and one for TBESH, maximum sixteen same-key subscribers each. Different-book contention and excess subscribers fail closed without a queue. One completed immutable book and one lexicon are retained; different-book acquisition evicts the previous book first. Cache keys include pin, digest, source identity and book. No authority, assignment, canonical reading or authorized response is cached.

Each producer has a five-second absolute production deadline and cancellation/post-settlement fences. Transport uses fixed HTTPS, redirect error, no credentials/referrer, no framework fetch cache or retry; validates response identity, bounded headers, actual byte count, SHA-256 and fatal UTF-8 before parsing. Group input cap is 32 MiB; lexicon cap is 4 MiB, with exact smaller descriptor sizes also enforced. Streaming uses a pre-sized bounded buffer, intrinsic typed-array views and a bounded consecutive-empty-read count. These are bounds on data/concurrency, not a hard process-memory guarantee.

Individual cancellation detaches only that subscriber. Last cancellation invalidates the producer and cache commit. A canceled/timed-out producer occupies its slot until its actual pending fetch/read/cancel promises settle, preventing overlapping replacements. Refused/late bodies are canceled without waiting in the caller response path; every boundary returns only a fresh fixed `StepSourceUnavailable` without cause or upstream details. Held source-format verses/entries remain immutable holds in an otherwise successfully acquired source.
