# Worked lesson: prepare and chant a first short verse

24 October 2026. First design draft for Daniel and Claude Code. Assumes basic pointed-Hebrew decoding; no prior trope or music vocabulary. This is a complete teaching flow on paper, not a delivered lesson or an auditioned content package. All learner-facing lines below are proposed copy, separate from previously approved release strings.

The detailed package now selects Genesis 1:1 as the primary authoring candidate, using catalogue A = units 0–2 and B = 3–6, with actual-context bridge practice. [STARTER-EXAMPLES.md](STARTER-EXAMPLES.md) records the source, alternatives and evidence limits; [IMPLEMENTATION-PACKAGE.md](IMPLEMENTATION-PACKAGE.md) collects the complete handoff.

## What this lesson should accomplish

The learner prepares a short real verse in manageable parts, practices a join, attempts the whole without a leading recording, and has a useful action if something is uncertain. An initial supported phrase is a worthwhile stopping point; the person can return to it without being failed or forced through a quiz.

This does not establish readiness for an entire public reading or transfer to a new passage. It teaches a small complete instance of the preparation process that later lessons repeat and extend.

## Example selection before content acceptance

Use an existing permitted human reference and matching pointed text. No text or rendered recording is copied into these planning files. The content reviewer must select and verify the actual verse and each phrase boundary before implementation is called ready:

- The text is manageable for a basic decoder, with word-specific support for any less familiar forms.
- Phrase boundaries and the join are musically/textually sensible, not an arbitrary equal division.
- The model is clear and at a usable pace. The first examples use a consistent voice and tradition; the existing actual assets must be auditioned rather than assumed suitable from metadata.
- Accurate word timing is available for the selected clip and text version. Never fabricate missing boundaries, split a maqaf group incorrectly or infer that an arbitrary syllable is a timed word.
- The ending and any other family patterns are known to the content reviewer and taught as needed. Do not choose a complex verse merely because it is short in word count.
- Include a prepared alternative when a public weekly reading has no suitable starter. Preserve a route back to the person's reading; do not describe a different example as their assigned verse.

Below, A and B mean musically appropriate practice phrases in that selected verse, not a claim that every Torah verse has exactly two practice phrases. If more parts are needed, repeat the same flow.

## Persistent practice surface

Keep the Hebrew readable and the current phrase clear, with playback and a way to return to the whole verse. During every sounding model, outline the current word, including in teaching examples and drills. The outline must be visible against phrase colors and in both themes; preserve instructional family colors. Light shading is a fallback to assess after reviewing outline visibility, not a second simultaneous competing treatment. Do not rely on color alone.

Provide pause/replay and the existing useful speed controls where accurate playback is supported. Tapping a difficult word opens existing word help without erasing the current task. Do not require recording or a microphone. Do not add a competing player or new reading infrastructure.

## The teaching flow

### 1. Hear what we are preparing

Proposed introduction: **"You’ll learn this verse in short parts, then try it without the recording."**

Show the whole verse and a clear play action. Prompt: **"Listen once and follow the words."** Word highlighting follows actual playback. An experienced learner may go directly to an independent attempt or the part they want to practice.

The action is orientation. Hearing once is not proof that anything was learned, and the lesson should not immediately ask which family was heard.

### 2. Make the words comfortable

Focus phrase A. Prompt: **"Read these words aloud. Open any word you want help with."**

Offer the existing syllable/stress/read-form help and the reference as needed. Do not teach the alphabet. Return any isolated word work to its phrase. No pronunciation accuracy claim follows from opening a word card or pressing Continue.

Learners already comfortable with the words can move on immediately.

### 3. Hear and echo the phrase

Prompt: **"Listen to this phrase. When it stops, chant it back."**

Play A, then allow a quiet interval and user-controlled replay. Begin with the same reference voice. Do not require matching its range or vocal quality. Suggested supporting line: **"Use a comfortable voice. Follow the tune and the words."**

If A is too much, offer a shorter musically sensible segment using verified boundaries. Return the segment to A afterward. Slower playback is an available aid; no exact speed or number of repetitions is prescribed for everyone.

### 4. Give the learner one thing to check

First comparison prompt: **"Try it without the recording. Then replay it and follow the words."**

After that attempt, offer a small focus: **"Were any words uncertain?"** Actions: **"Work on a word"**, **"Listen again"**, **"Continue"**.

For a later attempt, focus the phrase ending: **"Listen to the ending. Try the ending, then the whole phrase."** The actual musical attention cue must be written and checked with the chosen example by Daniel; this draft does not invent a verbal melody rule.

The learner can report uncertainty. No confident self-report becomes a verified voice score. If they cannot tell what differs, narrow the segment, replay the model, try again or seek optional competent help. Endless retries on the same unexplained question are not a repair strategy.

### 5. Offer the sound/sign connection when useful

After successful supported exposure, show the relevant ending mark and optionally its family name. Proposed route: **"See the mark for this ending"**. Keep the phrase in view and replayable.

For this first task, no family-name response is required. If an easy recognition activity is offered later, teach both choices first, keep models replayable, start with curated same-voice examples and explain what is being recognized. There is no opening same/different test and no unexplained switch between singers.

### 6. Prepare the next part

Use the same model → echo → independent try → focused comparison for B. Teach any new useful sound when encountered. Offer direct replay of A so learning B does not make the earlier part inaccessible.

A returning or ear-experienced reader may need only a model and one specific repair. A learner with sign knowledge may open the sign explanation directly. These alternate starts change support depth, not the underlying reading or musical expectations.

### 7. Teach the join explicitly

Prompt: **"Now connect the two parts. Listen across the join, then try it."**

Model the transition with enough words on both sides to preserve its musical sense, using the verified timing range. Let the learner practice that bridge, then A followed by B. Do not automatically interpret phrase boundaries as audible stops, or chop a musically dependent lead-in away from its ending.

If the isolated parts work but the whole fails, offer the bridge again rather than return to a family quiz or make the person restart all teaching.

### 8. Try the complete verse without a leader

Prompt: **"Chant the whole verse without the recording. Then listen and choose what to work on."**

Keep the intended readable text. The learner initiates the reference after their attempt; it must not automatically start underneath this attempt. Reference audio remains available as a preparation resource.

Offer three useful next actions:

- **"Practice a part"** → select a word/phrase and return to its model/repair loop.
- **"Practice the join"** → replay and rehearse the transition, then the whole verse.
- **"Try the whole verse again"** → another independent attempt, with reference available afterward.

Also offer **"Return later"** without forcing an accuracy declaration. The app cannot hear whether the verse was correct. Existing release strings and progress semantics must be reconciled with Claude before replacing or adding anything; this paper flow does not modify those contracts.

### 9. Make the next step concrete

Proposed closing explanation: **"You’ve practiced preparing a verse: learn the parts, connect them, try without the recording, and return to anything uncertain."** This describes the work rather than certifying competence.

Offer a later return to this verse and a route to the next useful phrase/verse in the selected reading. Keep optional targeted family practice beside that route. The next unit repeats the preparation method with appropriate variation; it does not immediately ask for an unsupported unfamiliar performance.

For a learner preparing scroll reading, later guided work moves through available text supports and recovery. That is a separate capability progression, not an additional hurdle before this first verse can be practiced.

## When things do not work

| Difficulty | Useful response |
| --- | --- |
| A word is hard to decode or stress | Open existing word aid/reference, practice it, return it to the phrase |
| The tune is hard to retain | A smaller sensible segment, stable model, echoing, then return to the phrase |
| Sounds are familiar but signs are confusing | Show the relevant mark in this text, model its phrase, make naming optional |
| The learner knows the signs but cannot produce the phrase | Return to the sound/echo/production loop without assigning a lower global rank |
| Each part works; the verse does not | Practice the bridge with surrounding words, then the full verse |
| The learner cannot judge their attempt | One specific comparison focus, shorter model, uncertainty allowed; optional human help |
| Audio is unavailable or fails to load | Honest playback state, retry/another verified example/return to reading; do not imply an unheard model taught the sound |
| The current reading is too demanding for a first task | Offer a curated starter while retaining a clear return to the selected reading |
