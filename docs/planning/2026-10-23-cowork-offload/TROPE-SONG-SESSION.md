# Trope song: recording session sheet

For the singer (Daniel or a CRC song leader). One page of reference to hold while recording. Source: ACTIVITIES.md section 15 (trope song, call and response). Names only: you sing the names on the melody you already use. This sheet specifies no tune.

**What the app does with it.** The app plays a short run of trope names; the learner sings it back; the next run follows. Each run is its own clip.

**Privacy.** Files go to `C:/private/trope-song/` and nowhere else. Never into a repo, a shared drive or an email. The recordings stay private until Claude Code wires them in. Nothing is posted or sent.

## Setup

- Quiet room, phone or mic about a hand-span from your mouth, no music or click track.
- Record each system on its own pass: Torah first, then haftarah.
- Pace: slow and even, a steady beat a learner can echo. Leave one beat of silence between names inside a run.
- Take length: one run per take, 5 to 15 seconds. Start recording, wait one second, sing, hold the last name, wait one second, stop.
- Do two takes of every run. Mark the better one in the file name at the end.
- Say nothing else on the take: no counting in, no comments, no "again".

## File names

`{system}-{nn}-{names}-{take}.wav` (or the phone's native format), for example `torah-03-munach-revia-t1.wav`. Two-digit run number from the lists below. Lower case, hyphens, no spaces. Keep a list of the runs you did in a text file, `trope-song-log.txt`, in the same folder.

## Haftarah system (record these 12 runs)

The same names, sung in the haftarah system. Use the same run numbers and names as the Torah list above, runs 01 to 12, with file names beginning `haftarah-`. Add one run:

| Run | Names, in order |
|---|---|
| 13 | the closing run of a haftarah (sof haftarah), as you would end the reading |

Skip the long chains in the haftarah pass unless you have time.

## Notes on the names

- Say each name the way you say it in your own teaching. Consistency across takes matters more than any one spelling.
- All run contents are proposed; Claude Code checks them against the course's lessons and may ask you for a few more runs.

## After the session

1. Check the folder holds both takes of each run plus the log.
2. Tell Daniel the folder is ready. Do not upload or send the files.
3. Claude Code will move or reference them when it builds the activity.
