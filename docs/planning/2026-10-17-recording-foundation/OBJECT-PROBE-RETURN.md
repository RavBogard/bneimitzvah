Fixed key acceptance/<run>/roundtrip-marker.bin; deterministic64 synthetic non-audio bytes, application/octet-stream. One nonoverwriting/no-random-suffix private PUT must return exact path/type/origin and strong quoted printable ETag<=256. HEAD verifies same64-byte object/ETag. Fixed output schema private-media-object-roundtrip/v1 has exactly ok,phase,outcome,writeAttempted,checks; five checks are putVerified,rangeVerified,staleEtagDenied,unsignedDenied,deleted. Before PUT failure is failed; after PUT attempt any failure is requires-reconciliation. No cleanup is attempted on a failing/uncertain step, and no second PUT/delete or replay exists. Opaque key/run remains reconstructible by the separate root operator; results never include paths, URLs, errors, headers, tokens or byte bodies.

## Bounds and deliberate limits

Per SDK/fetch/local signing await<=10s, object body byte-progress idle<=5s, at most64 consecutive empty reads, total<=90s, application-level provider calls<=12 (normal sequence11). Successful body exactly16 bytes; stale/unsigned bodies<=4096 and discarded. Byte fetches use redirect:error,credentials:omit,no-referrer,no-store, exact origin/path and fixed headers. Empty error bodies are supported. Cancellation is best-effort/nonawaited, late responses are discarded and cannot start the next action or report success; an accepted request is never described as physically canceled.

Root expressly accepts the existing trusted-provider exception for pinned SDK CONTROL-plane JSON. SDK has no public response-byte/redirect-control hook; it may parse unbounded control JSON and perform internal protocol/redirect work.10s abort/deadline/retry0 does not preempt synchronous JSON parsing or guarantee a literal wire-dispatch count. Monotonic freshness is checked when control returns, so no later action/success follows an exceeded deadline. No runtime dispatcher interception, SDK patch or arbitrary endpoint workaround was added. Strict object-byte fetch caps remain in force. This is a controlled-build provider observation, not a production byte-transport guarantee.
