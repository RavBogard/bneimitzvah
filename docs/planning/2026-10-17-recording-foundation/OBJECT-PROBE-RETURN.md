Successful body exactly16 bytes; stale/unsigned bodies<=4096 and discarded. Byte fetches use redirect:error,credentials:omit,no-referrer,no-store, exact origin/path and fixed headers. Empty error bodies are supported. Cancellation is best-effort/nonawaited, late responses are discarded and cannot start the next action or report success; an accepted request is never described as physically canceled.

Root expressly accepts the existing trusted-provider exception for pinned SDK CONTROL-plane JSON. Monotonic freshness is checked when control returns, so no later action/success follows an exceeded deadline. No runtime dispatcher interception, SDK patch or arbitrary endpoint workaround was added. Strict object-byte fetch caps remain in force. This is a controlled-build provider observation, not a production byte-transport guarantee.
