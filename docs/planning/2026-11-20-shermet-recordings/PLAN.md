# Cantor Wendy Shermet in the CRC reader

Daniel authorized integration on November 20 and confirmed that CRC may stream the human recordings on its public site and shared reading links. Credit Cantor Wendy Shermet and Temple Israel, Omaha. The permission confirmed for this milestone is public CRC streaming. A portal for Omaha is a separate future decision.

## First public release

1. Match six Torah verses, Exodus 35:1–6, and three haftarah verses, Micah 7:18–20, to individual performances. Use the explicitly labeled full-verse recordings on the credited Exodus study sheets and the three individually labeled rows on Temple Israel's Micah page. Keep source receipts and downloaded media outside the repository. Record the source ID and SHA-256 for each verse. [Exodus 35:1–3](https://voices.sefaria.org/sheets/386127) · [Exodus 35:4–6](https://voices.sefaria.org/sheets/548290) · [Micah 7:18–20](https://www.templeisraelomaha.com/micah-718-20.html)
2. Offer Shermet by name on covered passages. Preserve PocketTorah's word timings and use each Shermet performance for its own full verse. Keep the recording credit available during practice. On a coverage gap, indicate which recording is available. Keep media outside Git and the offline packs.
3. Check SHA-256, decodability and duration for each source file. Test switching, verse looping, missing recordings, and ordinary PocketTorah playback. Review the public recording-access boundary independently. Run the repository checks and CI, then test the public deployment at the two passage links.

For the expanded catalog, choose a delivery arrangement with Omaha that can handle expected traffic, and confirm any additional use such as offline copies before enabling it.
