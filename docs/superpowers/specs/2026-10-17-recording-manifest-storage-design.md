## Per-slot late-write retirement

Candidate per-slot protocol: create an opaque **31-byte non-audio permit P**, create-only; obtain strong ETag A. The trusted server writes the buffered even-length chunk with ifMatch=A, allowOverwrite=true, addRandomSuffix=false, multipart:false. It never resets P/A. Retire by conditionally replacing the current object with a distinct **33-byte non-audio marker R**, verify current-origin R, retain it permanently and fence all later slot work in SQL. Odd marker lengths cannot equal any permitted even chunk representation; require observed ETag changes and retain strong provider ETag/OCC semantics as an explicit trust premise. No post-retirement DELETE/recreate path or app path may restore A.

Independent review accepts this architecture and the bounded proof. Require R's observed ETag to differ from BOTH A and the replaced B, not merely A. This is an empirical check plus the stated provider strong-ETag premise.

Every admitted slot must be known to account-independent cleanup, including permit creation/upload that timed out or never returned. Cleanup must establish R rather than treating an absent HEAD/expired lease as proof no write can arrive. Final physical/current-object confirmation requires the same claim and verified R after provider I/O; old audio cannot become playable while cleanup retries.
