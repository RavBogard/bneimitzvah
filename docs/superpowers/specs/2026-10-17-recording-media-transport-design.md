The adapter has closed ordinary PUT, metadata lookup and full private GET operations. Accept only trusted internal slot bindings: the one configured store/generation, opaque asset UUID, index0..27, exact byte length/hash and strong tag where required. Derive only `recordings/v1/<asset UUID>/chunk-<two digit index>`. No URL/header/token/endpoint from a request, arbitrary key/store, multipart/delegation/presign, DELETE/recreate, range fallback, transparent retry or SDK byte/control execution. Future composition must prove durable admission/opening and fresh authority before and after I/O; this adapter is not that authorization layer.

Use a small raw Node HTTPS client, verified TLS, fixed host/port/path and bounded parsing. Compare semantic PUT/metadata/direct-GET mapping against the actual pinned Blob2.8.2 SDK under network-blocked mocks; do not guess wire fields. PUT is fixed API13/private/octet-stream/random-suffix-off/cache60/attempt0. P31 is create-only, U is even2..1048576 bytes with exact A condition, R33 uses the explicit current strong condition; markers are fixed odd non-audio bytes. Copy/hash-bind U into owned memory before awaits; caller mutation cannot change dispatched bytes. Successful U/R tags must differ from the known replaced/permit tags. Success JSON proves metadata only, not current full bytes.

Metadata lookup is the SDK's control GET, not an HTTP HEAD expecting JSON. Validate fixed path/private origin/no credentials/query/fragment, content type, bounded safe size and strong ETag; never follow a returned URL. Private GET constructs the fixed origin/key with cache0 and direct OIDC authentication from the pinned mapping, sends exact If-Match plus Accept-Encoding identity, and requires200, no Content-Encoding, exact decimal length/MIME/strong expected tag, complete EOF/count/hash. Native HTTPS already binds its socket destination; redirects never change it. Copy received bytes into owned bounded storage while hashing; do not return them before validation. Caller must still perform fresh user/receipt authority before releasing bytes.
